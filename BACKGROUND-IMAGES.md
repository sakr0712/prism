# PRISM background image slots

Place your banner images inside the `public` folder using these exact names:

- `prism-hero-banner.jpg` — homepage hero; use a wide image (recommended 2400 × 1400 px). Keep the important subject toward the right side so the headline remains readable on the left.
- `prism-about-banner.jpg` — About PRISM section; use a subtle production, fabric, or atelier image. Dark images work best.
- `prism-mission-banner.jpg` — Mission & Vision section; use an abstract textile, close-up fabric, or brand-pattern image.

The website already adds premium overlays, so the text remains readable. If an image is missing, the original gradient background remains visible.

Recommended file format: compressed JPG or WebP, ideally below 500 KB each.
